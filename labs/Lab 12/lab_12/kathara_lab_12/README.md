# Kathara Lab 12: The Transport Layer

This directory contains the Kathara Lab 12 topology.

Start the lab from this directory:

```sh
kathara lstart
```

Connect to a machine if a terminal does not open automatically:

```sh
kathara connect m1
```

Stop and clean up the lab:

```sh
kathara lclean
```

The topology is defined in `lab.conf`. Interface addresses and routes are configured with explicit `ip` commands in the `*.startup` files.
