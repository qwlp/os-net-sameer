Netkit

2.       Netkit is a very useful wrapper around Jeff Dike's User Mode Linux. It makes the
         configuration of virtual network devices fairly straightforward (once you get the hang
         of it - it can take a bit of getting used to initially). In effect, Netkit allows an un-
         privileged user (for example you when sitting at a University machine) to do all sorts
         of Network configuration that would normally require root (Unix jargon for what
         Windows users would describe as "administrator") privilege.

3.       The Netkit version installed in the lab machines is Netkit-JH (https://netkit-
         jh.github.io/), an updated version of the original netkit

4.       Netkit can be used in two modes:
         ◦ one machine terminal at a time using v*** instructions
         ◦ several machine terminals (xterms) together, configured as a network, using l***
            instructions

5.       You will use the single machine v*** instructions in this first lab.

6.       Spend a few minutes familiarising yourself with the Netkit-jh man pages here.

Wireshark
Health Warning: You are about to use a very powerful tool with restraint. If you
capture the traffic of users without their informed consent, then you probably
contravene the Computer Misuse Act.
7.       Wireshark is a graphical network traffic analyser. In the lab sessions throughout this
         module, you will use it to analyse traffic that has been captured from your Netkit
         virtual machine networks. Wireshark can also be used to capture network traffic. We
         will not be doing this.

8.       In order to present you with a graphical representation of data traversing a network,
         Wireshark "knows" how to interpret the stream of ones and zeros in many different
         protocols (Ethernet, IP, TCP, DNS, HTTP etc). The graphical interface then allows
         you to filter what you want to look at (only DNS traffic for example, or perhaps
         traffic destined for TCP port 80 on the machine with IP address 146.227.150.225).

Getting started with Netkit

Netkit is a project for creating virtual network devices (routers, switches, servers, etc) which
can be connected to form a full network on a single host machine. This can be useful for
running network related experiments or for education. Netkit machines are User-mode Linux
instances which are lightweight and do not require root access to run.

Netkit is pre-installed on the lab machines. However, there is no icon to access an
application window.

To use Netkit simply type the appropriate Netkit command at the system prompt.

Creating multiple netkit virtual machines

Netkit can be used to simulate different sizes of networks, from just two machines to many
dozens – just how many can be created is largely dependent upon the memory capacity of the
hosting machine. In this next exercise, you are going to build a small network with just two
hosts:




22.    In the host system terminal, start two netkit vms:


.../lab_10$ vstart pc1 --eth0=A
.../lab_10$ vstart pc2 --eth0=A


       The two vms are connected to the same collision domain. Therefore, they will be able
       to message each other, once their respective network interfaces have been configured
       with an IP address and a netmask.

23.    In the netkit terminal pc1, enter:


root@pc1:~# ip addr add 10.0.0.1/24 dev eth0
root@pc1:~# ip addr show dev eth0


24.    The second command displays the IP address and netmask for pc1
       NB the IP address is 10.0.0.1 and the netmask is /24
