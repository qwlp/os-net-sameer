## Getting Started with Kathara

Kathara builds upon Docker to provide virtual network laboratories. Unlike Netkit, Kathara uses labs defined by `lab.conf` files, but for simple commands, we can interact with it via the host terminal.

### 1. Simple Virtual Machine (Host)
Instead of `vstart`, we will use Kathara's basic docker-like execution to spin up a machine connected to a virtual collision domain.

#### Create a single machine:
```bash
kathara lstart
```
*(Note: Kathara usually looks for a lab directory. For a single machine, ensure a `lab.conf` exists in your folder or use `kathara lstart` if you have a predefined setup.)*

### 2. Creating a Network (Two Machines)
To simulate the two-machine network (`pc1` and `pc2`) on collision domain `A`:

1. Create a directory for your lab:
   ```bash
   mkdir -p ~/ctec1704/lab_10_kathara
   cd ~/ctec1704/lab_10_kathara
   ```

2. Create a `lab.conf` file to define the network:
   ```text
   pc1[0]=A
   pc2[0]=A
   ```

3. Start the lab:
   ```bash
   kathara lstart
   ```

4. Access the machines:
   ```bash
   kathara connect pc1
   kathara connect pc2
   ```

### 3. Network Configuration
In the `pc1` and `pc2` terminals, configure the interfaces:

**On pc1:**
```bash
ip addr add 10.0.0.1/24 dev eth0
ip link set eth0 up
```

**On pc2:**
```bash
ip addr add 10.0.0.2/24 dev eth0
ip link set eth0 up
```

### 4. Capturing Traffic
1. Create a capture directory on your host:
   ```bash
   mkdir -p ~/ctec1704/captures
   ```

2. Capture traffic from `pc2` using `tcpdump`:
   ```bash
   # Inside pc2 terminal
   tcpdump -v -i eth0 -w /hosthome/ctec1704/captures/ping1.pcap
   ```

3. Send pings from `pc1`:
   ```bash
   # Inside pc1 terminal
   ping -c 2 10.0.0.2
   ```

4. Stop the capture with `Ctrl+C` in the `pc2` terminal.

### 5. Analysis
1. Open the captured file in **Wireshark** on your Ubuntu host:
   ```bash
   wireshark ~/ctec1704/captures/ping1.pcap
   ```

2. Analyze the ICMP and ARP traffic as per the original lab objectives.

### 6. Cleanup
To stop and remove the lab environment:
```bash
kathara lclean
```
